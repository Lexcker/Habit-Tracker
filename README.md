# Rootwork — Habit Tracker

## 1. Название и описание

**Rootwork — Habit Tracker** — это веб-приложение для создания полезных привычек и отслеживания личного прогресса. Оно помогает пользователю планировать ежедневные дела, контролировать выполнение привычек и достигать поставленных целей.

Приложение имеет простой интерфейс и подходит для людей, которые хотят организовать своё время и сделать полезные действия частью повседневной жизни.

## 2. Возможности

Основные функции приложения:

- Регистрация и вход в аккаунт.
- Создание, редактирование и удаление привычек.
- Отметка выполненных привычек.
- Отслеживание серий последовательных выполнений.
- Создание личных целей и контроль прогресса.
- Просмотр статистики и графиков.
- Получение достижений за выполнение задач.
- Настройка внешнего вида приложения (светлая и тёмная темы).
- Просмотр личного профиля.

## 3. Требования

Для работы приложения необходимы:

- Современный веб-браузер (Google Chrome, Mozilla Firefox, Microsoft Edge или Safari).
- Компьютер или другое устройство с доступом к браузеру.
- Подключение к интернету для загрузки внешних библиотек и шрифтов.

**Используемые технологии:**
- HTML5 — структура страниц.
- CSS3 — оформление приложения.
- JavaScript — работа функций приложения.
- Chart.js — создание графиков.
- Lucide — значки интерфейса.
- LocalStorage — сохранение данных в браузере.

Установка дополнительных программ и баз данных не требуется.

## 4. Установка

Чтобы запустить приложение:

1. Откройте страницу проекта на GitHub: https://github.com/Priyanka5103/habit-tracker
2. Нажмите кнопку **Code**.
3. Выберите **Download ZIP**.
4. Распакуйте скачанный архив в удобную папку.
5. Откройте папку проекта.
6. Найдите файл `index.html`.
7. Откройте его двойным щелчком мыши в браузере.

Для более стабильной работы сохранения данных можно запустить локальный сервер:

1. Откройте терминал в папке проекта.
2. Выполните команду:

```bash
python -m http.server 5500
```

3. Откройте браузер и перейдите по адресу:

```text
http://localhost:5500
```

После этого приложение будет готово к работе.

## 5. Пример использования

Рассмотрим пример работы с приложением:

1. Пользователь открывает приложение и регистрирует аккаунт.
2. После входа он попадает на главную страницу с панелью управления.
3. Переходит в раздел привычек и добавляет новую привычку «Читать книги».
4. Выбирает периодичность выполнения и устанавливает цель.
5. Каждый день отмечает привычку как выполненную.
6. В разделе прогресса просматривает статистику и результаты.
7. За регулярное выполнение привычек пользователь получает достижения.

Таким образом, приложение помогает следить за ежедневными действиями и видеть собственные результаты.
