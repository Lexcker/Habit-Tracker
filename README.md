# СПРАВОЧНИК ПО ПРОЕКТУ HABIT TRACKER

**Название проекта:** Habit Tracker (Rootwork)  
**Тип проекта:** Веб-приложение  
**Назначение:** Создание, отслеживание и анализ полезных привычек.

## 1. Общая информация о проекте

Habit Tracker — это веб-приложение, которое помогает пользователям формировать полезные привычки, контролировать ежедневную активность и отслеживать личный прогресс.

Пользователь может создавать привычки, отмечать их выполнение, устанавливать цели, просматривать статистику и получать достижения.

Проект разработан с использованием HTML5, CSS3 и JavaScript. Для хранения информации используется LocalStorage браузера.

## 2. Справочник полей данных привычки

В данном разделе описаны основные поля, используемые для создания и управления привычками.

### 2.1. Название привычки (Name)

- **Описание:** Название привычки, которую пользователь хочет отслеживать.
- **Тип данных:** String (строка).
- **Значение по умолчанию:** Не установлено.
- **Пример:** `"Читать книги"`.

- **Значение по умолчанию:** Не установлено.

### 2.3. Частота выполнения (Frequency)

- **Описание:** Определяет периодичность выполнения привычки.

## 3. Основные функции приложения

1. **Регистрация и авторизация** — создание аккаунта и вход пользователя.
2. **Управление привычками** — добавление, редактирование и удаление привычек.
3. **Отслеживание выполнения** — отметка привычки как выполненной или невыполненной.
4. **Управление целями** — создание целей и отслеживание их выполнения.
5. **Статистика** — просмотр графиков и результатов за разные периоды.
6. **Достижения** — получение специальных значков за выполнение условий.
7. **Настройки** — изменение темы оформления и параметров приложения.

## 4. Хранение данных

Для хранения информации используется браузерное хранилище `localStorage`.

В нём сохраняются:
- данные пользователей;
- список привычек;
- цели;
- достижения;
- настройки приложения;
- выбранная тема оформления.

Данные сохраняются в браузере и остаются доступными после обновления страницы. Серверная база данных в проекте не используется.
